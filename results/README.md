# results/

Output directory for experiment results, predictions, and visualizations. Files are generated by `scripts/run_experiments.py`, `scripts/reproduce_results.py`, `predict.py`, and `visualize.py`.

## Directory Structure

Each run creates a timestamped JSON file or a named subdirectory:

```
results/
├── README.md
├── example_run/                              # From --output_dir results/example_run
│   ├── results_20260327_212306.json          # Full experiment results
│   └── prediction_example.json               # Single prediction output
├── figure6_dimension_sweep.png               # From reproduce_results.py --figure 6
└── ...
```

---

## Output Formats

### Experiment Results JSON (`results_YYYYMMDD_HHMMSS.json`)

Generated by `scripts/run_experiments.py`. Contains all experiment results in a single file.

**Top-level keys** (one per experiment, only present if that experiment was enabled):

```json
{
  "time_probing": [...],
  "prompt_sensitivity": [...],
  "embedding_analysis": {...},
  "timeline_comparison": {...},
  "dimension_sweep_<model>": {...}
}
```

#### `time_probing` — Table 1

Array of per-model results using prompt P7.

```json
{
  "model": "clip-vit-b32",
  "prompt": "P7",
  "mae": 9.24,                    // Mean Absolute Error (years)
  "tai": 0.769,                   // Time Awareness Index (0-1)
  "timing": {
    "total_inference_ms": 593.2,   // Total wall-clock time
    "avg_per_image_ms": 0.06       // Per-image inference time
  }
}
```

#### `prompt_sensitivity` — Table 2

Array of per-model, per-prompt results.

```json
{
  "model": "clip-vit-b32",
  "prompt": "P1",                  // Prompt ID (P1-P9)
  "mae": 21.26,
  "tai": 0.653
}
```

#### `embedding_analysis` — Table 4

Ranking metrics for KPCA and UMAP 1D projections. Keys are `(model, method)` tuples.

```json
{
  "('CLIP', 'kpca')": {
    "spearman_rho": 0.96,          // Spearman's rank correlation
    "kendall_tau": 0.84,           // Kendall's tau
    "delta_MNDL": 0.84             // Modified Normalised Damerau-Levenshtein
  },
  "('CLIP', 'umap')": {
    "spearman_rho": -0.93,         // Negative = reversed direction (corrected in evaluation)
    "kendall_tau": -0.88,
    "delta_MNDL": -0.88
  }
}
```

#### `timeline_comparison` — Table 5

Per-model comparison of all 6 methods.

```json
{
  "clip-vit-b32": {
    "Time Probing":          { "mae": 9.24, "tai": 0.769 },
    "UMAP":                  { "mae": 13.01, "tai": 0.526 },
    "Bezier(R^N,NN)":        { "mae": 9.28, "tai": 0.764 },
    "Bezier(R^N,Int)":       { "mae": 9.24, "tai": 0.766 },
    "Bezier(R^S(S=13),NN)":  { "mae": 8.89, "tai": 0.791 },
    "Bezier(R^S(S=13),Int)": { "mae": 8.80, "tai": 0.795 }
  }
}
```

#### `dimension_sweep_<model>` — Figure 6

MAE and TAI per KPCA dimension. Keys are dimension numbers (as strings).

```json
{
  "1":  { "mae": 51.23, "tai": 0.121 },
  "2":  { "mae": 19.41, "tai": 0.377 },
  "13": { "mae": 8.80,  "tai": 0.795 },
  "20": { "mae": 8.68,  "tai": 0.801 }
}
```

### Prediction JSON

Generated by `predict.py --output json --save <path>`. Array of per-image predictions.

```json
[
  {
    "predicted_year": 1972,
    "inference_ms": 1766.2,
    "image": "data/TIME10k/1972/800px-1972_Lancia_Stratos.jpg",
    "model": "clip-vit-b32",
    "method": "bezier"
  }
]
```

When using `--method time_probing`, an additional `confidence_scores` field contains the top-5 year scores:

```json
{
  "predicted_year": 1971,
  "confidence_scores": {
    "1971": 23.79,
    "1972": 23.45,
    "1973": 23.42
  },
  "inference_ms": 12455.2,
  "image": "photo.jpg",
  "model": "clip-vit-b32",
  "method": "time_probing"
}
```

### Visualization PNGs

Generated by `visualize.py --save <path>` and `reproduce_results.py --figure 6`.

| Command | Output | Description |
|---|---|---|
| `visualize.py manifold` | `manifold.png` | 2D/3D KPCA embedding space colored by year |
| `visualize.py timeline` | `timeline.png` | 1D KPCA and UMAP projections side-by-side |
| `visualize.py bezier` | `bezier.png` | 3D Bezier curve through embedding space |
| `visualize.py dimension_sweep` | `sweep.png` | MAE vs KPCA dimension (Figure 6) |
| `visualize.py distribution` | `dist.png` | Predicted vs ground truth year distributions |

## Example Run

The `example_run/` subdirectory contains sample outputs from a lightweight test (CLIP ViT-B/32, precomputed embeddings, CPU). These serve as reference for the expected output format.
