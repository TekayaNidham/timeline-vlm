# scripts/

Benchmark and paper reproduction scripts. Run from the **repository root**.

| Script | Purpose | Example |
|---|---|---|
| `reproduce_results.py` | Reproduce specific tables/figures | `python scripts/reproduce_results.py --table 5` |
| `run_experiments.py` | Full YAML-driven experiment pipeline | `python scripts/run_experiments.py --config configs/lightweight_test.yaml` |

See [`docs/reproducing_results.md`](../docs/reproducing_results.md) for detailed guide.
